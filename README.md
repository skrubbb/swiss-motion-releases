# Swiss Motion — releases

Downloads of the Swiss Motion After Effects panel (signed ZXP).

Each release has two files:

- **SwissMotion-X.Y.Z.zxp** — Full edition
- **SwissMotion-X.Y.Z-Lite.zxp** — Lite edition

Install the .zxp with a ZXP installer (e.g. aescripts ZXP Installer), then restart After Effects.
The panel needs a personal license key. Not for sale · please don't share or redistribute.
